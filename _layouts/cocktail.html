{% comment %} The ingredient list is FULL, not triaged the way food's main_ingredients is — no completeness/substitution split, no pantry demotion. Keys, each earning its place from the real data: amount the quantity AS WRITTEN ("0.5 oz", "3 dashes") — the display string, which carries units a number cannot ml the same quantity in millilitres, for ratios and scaling. ABSENT on purpose where the unit is not volumetric — a dash is not 0.8 ml in any way worth writing down. STRING OR LIST — a list means "either would do", never "and". character a property of THIS RECIPE'S use of the bottle, not of the bottle in the abstract (#441) — e.g. blackstrap. LIST. suggestion the bottle NAME(S) ONLY, never reasoning (#457). STRING OR LIST. note the reasoning that used to get smuggled into `suggestion` (#457) — its own line, always visible, no interaction. HEADLINE, CLASS LINE, CHARACTER, NOTE — settled 2026-08-24 after a design pass on #465/#460. The headline is `suggestion` when present (you shop by bottle name), falling back to `item`.
