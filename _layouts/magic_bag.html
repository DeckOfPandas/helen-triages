{% comment %} THE STANDING CAVEAT, AND WHY IT IS HERE RATHER THAN IN THE FRONT MATTER. Helen's ask, 2026-08-26: "I should dash off ingredients lists, promising future Helen that they're not complete." A promise you have to retype on every file is a promise you will skip on the day you are in a hurry -- which is precisely the day you are dashing one of these off. So the collection makes the promise instead, in the same words every time, and there is no per-file field to forget. It sits ABOVE the ingredients because its whole job is to set the expectation before the list is read, not to apologise for it afterwards. If an entry ever genuinely IS complete, the fix is an opt-in `ingredients_complete: true` and a second branch here. Not built: no entry has wanted it yet, and the default has to stay "incomplete" regardless. {% endcomment %}
