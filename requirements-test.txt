# Test dependencies only. The site itself needs nothing from Python.
#
# What CI installs. Exact pins, not floors: a floor lets CI and the container
# each install whatever is newest, and then no file records the versions the
# suite is green on (#1203).
#
# The container installs the same versions from elsewhere: pytest from the
# kit's .devcontainer/Dockerfile, PyYAML from .devcontainer/requirements.txt,
# Playwright from PLAYWRIGHT_VERSION in .devcontainer/kit.env.
# tests/test_ci_matches_container.py fails when any pair differs. pytest moves
# with a kit sync, so it is in dependabot.yml's ignore list.
pytest==9.1.1
PyYAML==6.0.3

# PLAYWRIGHT'S PYTHON BINDING, for the headless smoke test of both indexes
# (#1200). Its sibling is the npm playwright baked into the image for
# scripts/browser/: that one is for a human or a session to LOOK at a page with,
# and this one is for a test that needs the suite's own Jekyll build, which
# tests/test_rendered_pages.py already makes behind a session fixture.
#
# ONE NUMBER FOR BOTH. npm and PyPI must both publish the version, so the two
# bindings resolve one Chromium and the image carries one browser.
#
# THE NUMBER LIVES IN THREE PLACES: here, PLAYWRIGHT_VERSION in
# .devcontainer/kit.env (the image's npm and pip installs both read it), and
# scripts/browser/install.sh. tests/test_browser_harness.py and
# tests/test_ci_matches_container.py hold them together, and `playwright` is in
# dependabot.yml's ignore list because a bot can move only this one. Bump the
# three by hand, as a set, and rebuild the image.
#
# INSTALLING THIS PACKAGE DOES NOT INSTALL A BROWSER -- `playwright install
# chromium` does, and that is a Dockerfile step. So CI gets the binding and no
# browser, which means any browser test MUST skip on whether a browser can
# actually LAUNCH, never on whether the import succeeds. Skipping on the import
# would turn CI red the moment this line landed, which is exactly the
# "expected to fail" arrangement Helen ruled against on 2026-09-20 (#1191).
playwright==1.63.0
