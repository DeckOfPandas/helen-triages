Every row is the same four marks at different coordinates, and the arithmetic that turns °C into a position lives in the stylesheet, not here — so this file's only job is to hand over numbers. That keeps the axis re-scalable from one place (the $tc-min/$tc-max pair in assets/css/reference-demo.scss) rather than from ~40 call sites. PARAMETERS ARE READ AS include.x, NOT AS BARE NAMES. Jekyll only binds them onto the `include` object; a bare {{ spec }} would silently resolve against the including page's own scope instead — which is worse than failing, because it works whenever the page happens to have a variable of that name and breaks the moment it doesn't. "OUT AT", NOT "PULL AT". Helen: "I don't love the word 'pull'... mostly because it's American." Out at is shorter, reads as plain English, and stays true for a pan, a grill or a bain-marie where "out of the oven" wouldn't. It also matches the calculator, which says "in at 14:20, out at 17:05" -- so one verb now carries the same meaning across both instruments, and the schedule hands straight over to the thermometer figure. The DATA still uses `out_at_min`/`out_at_max`, deliberately: renaming those keys means touching _layouts/recipe.html, the reference page and the guard tests at once, and the field name is nobody's reading experience. Display language changed here; the existing pages' own "Pull at" column headings are a copy pass still to do. THE CARRYOVER BAR IS ONLY DRAWN WHEN THERE IS A GAP TO DRAW. Salmon's carryover is 1–2°C and its out-at and rested ranges overlap, so there is no clear space between them; a dotted connector there would be drawn on top of the bars it's meant to join and read as noise. Beef's 4–6°C carryover leaves a real gap, and that gap is the whole point of the chart. {% endcomment %} {% assign spec = include.spec %} {% comment %} FOUR SHAPES, ONE ROW. internal_temperatures.yml deliberately isn't uniform (see its own header): a doneness level has pull/rested, a whole bird has an endpoint, a cured ham has a target, and a tough cut has tender_at and no out-at temperature at all because collagen breakdown isn't a doneness.
