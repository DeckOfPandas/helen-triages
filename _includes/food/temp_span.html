Parameters label the protein's name doneness a doneness hash from _data/food/internal_temperatures.yml No hover text since 2026-10-08 (#1326) -- see temp_row.html. WHY THIS ISN'T `| map: "out_at_min" | sort | first`, WHICH IS THE OBVIOUS WAY. `doneness` is a HASH, and iterating a hash in Liquid yields [key, value] PAIRS — so `map: "out_at_min"` asks a two-element array for a property it doesn't have and quietly returns a list of nils. `sort | first` on that gives nil, the coordinate renders as `--a:;`, and the bar silently collapses. It fails without erroring, which is the worst kind, and it was written that way here first before the rendered output gave it away. Looping over the pairs and comparing lvl[1] is the version that works. Computed rather than typed so that adding a doneness level upstream reshapes this bar too — the summary can't drift from the detail above it. {% endcomment %} {% assign lo = 999 %} {% assign hi = 0 %} {% for lvl in include.doneness %} {% if lvl[1].out_at_min and lvl[1].out_at_min < lo %}{% assign lo = lvl[1].out_at_min %}{% endif %} {% if lvl[1].rested_max and lvl[1].rested_max > hi %}{% assign hi = lvl[1].rested_max %}{% endif %} {% comment %} Tuna has out-at figures but no rested ones — fall back to the out-at ceiling so its bar still reaches its own hottest level. {% endcomment %} {% if lvl[1].out_at_max and lvl[1].out_at_max > hi %}{% assign hi = lvl[1].out_at_max %}{% endif %} {% endfor %}
