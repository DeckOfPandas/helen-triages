--- layout: default title: "Glasses" permalink: /cocktails/reference/glasses/ --- {% comment %} GLASSES (#295). A spec, not an inventory: what each glass type holds on the market, nothing about the cupboard. All the glasses at relative scale with the mean and range in ml, and nothing else in the page body. Sources are in _data/cocktails/glass_survey.yml. Every number is a lookup: `heights_mm` and `typical_ml`, generated by scripts/glass_survey_stats.py. `base_centre`, sent as `--glass-shift`, stands a drawing's base over its label, not its box. Alphabetical by the printed name, on purpose. Every ml is rounded to the nearest 10 here and nowhere else; the data keeps whole ml. The name is the first `icons:` key for the drawing that `canonical_glasses` does not correct, so the page uses a drink page's words. `survey_only_types` is for a type that borrows a drawing but has its own size; it is empty, and its loop is kept. {% endcomment %} {% assign g = site.data.cocktails.glasses %} {% assign tallest_mm = 0 %} {% for icon in g.all_icons %} {% assign mm = g.heights_mm[icon] | times: 1.0 %} {% if mm > tallest_mm %}{% assign tallest_mm = mm %}{% endif %} {% endfor %} {% comment %} One row per glass, "name|type|drawing", so that sorting the strings sorts by the printed name. A lookup key is always assigned before use: Liquid silently returns nil for a lookup nested inside another. {% endcomment %} {% assign rows = "" | split: "" %} {% for icon in g.all_icons %} {% assign name = nil %} {% for pair in g.icons %} {% assign spelling = pair[0] %} {% if pair[1] == icon and g.canonical_glasses[spelling] == nil %} {% assign name = spelling %}{% break %} {% endif %} {% endfor %} {% unless name %}{% assign name = icon | replace: "-", " " %}{% endunless %} {% capture row %}{{ name }}|{{ icon }}|{{ icon }}{% endcapture %} {% assign rows = rows | push: row %} {% endfor %} {% for pair in g.survey_only_types %} {% assign key = pair[0] %} {% assign name = pair[1].spellings | first %} {% capture row %}{{ name }}|{{ key }}|{{ pair[1].draws_as }}{% endcapture %} {% assign rows = rows | push: row %} {% endfor %} {% assign rows = rows | sort %}
