WHY THIS PAGE EXISTS, and it is HANDOVER §11.2.1 rather than convenience: how a glass sits in a card panel is a question about a SIZE, and neither Helen nor I can produce the comparison by looking at the real index — the cards are scattered through 114 drinks in random order, so no two glasses that need comparing are ever next to each other. "Is the flute too tall" is a comparison, and a comparison has to be built before it can be made. IT USES THE SITE'S OWN CSS, NOT A COPY. Every swatch below is a real `.drink-card` containing a real `.drink-card-glass`, pulling the icon in with the same include tag the index uses, so the panel width, the wash, the width cap, the stroke weight and the centring are the live rules — not a reproduction of them. _dev/emboss.html's own note is the reason: its predecessor reproduced the treatment by hand, applied half of it, and made the font look like the fault. A swatch that draws itself cannot be trusted about the thing it is swatching. EVERY NUMBER IS COUNTED LIVE — the drink counts from site.cocktail_drafts, the heights from glasses.yml, the tallest glass by scanning rather than by being written down. A swatch page with a stale number in it is worse than no swatch page, because it looks like evidence. THE MODELS ARE A COMPARISON SWITCH, and the convention that comes with one is that the losers get DELETED once Helen picks.
